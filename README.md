# Chrome Page

Chrome Page — это расширение для Chrome, которое превращает новую вкладку в удобное рабочее пространство для закладок. Оно позволяет быстро просматривать и открывать закладки в виде компактной плитки, искать их по названию и адресу, переходить между папками, управлять закладками и настраивать внешний вид страницы.

Расширение поддерживает светлую, тёмную и системную тему, настройку количества колонок, размера плиток, отступов, радиусов, размытия, фонового свечения и прозрачности интерфейса. Закладки отображаются с favicon, а изменения в закладках синхронизируются автоматически.


## Проверка

Для локальной проверки проекта:

```bash
npm test
npm run check
```

CI автоматически запускается для push в `main` и для pull request в `main`.
